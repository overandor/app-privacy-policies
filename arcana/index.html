Emberiris — Privacy Policy

Last updated: September 2025

Local-First · No Tracking · No Cloud

Overview

Emberiris is a privacy-first iMessage analysis tool. All data processing happens locally on your Mac. Your messages, contacts, and analysis results never leave your device.

Data We Access

  • iMessage database: Emberiris reads your local Messages database to import and analyze conversations. This data stays on your Mac.
  • Contacts: Emberiris accesses your Contacts to resolve phone numbers to names. Contact data is used locally for display only.
  • Microphone: Used for ATLAS Mediator voice input. Audio is processed locally and not recorded or stored.
  • Speech Recognition: Used for ATLAS voice-to-text. Recognition happens on-device.
  • Photos/Media: Message attachments are imported from the local iMessage attachment store for display within the app.

Data We Do NOT Collect

  • We do not collect, transmit, or sell any personal data.
  • No analytics or tracking.
  • No cloud servers. No telemetry. No advertising SDKs.
  • No account required. No login. No email.

Local AI Processing

Emberiris includes a bundled local AI model (Ollama) for the ATLAS Mediator feature. All AI processing happens on your Mac's CPU/GPU. No conversation data is sent to any external server.

If you optionally configure a cloud LLM provider (Groq, OpenRouter), message text may be sent to that provider for mediation responses. This is opt-in and requires manual API key configuration.

Multilingual Translation

Emberiris's ATLAS Mediator supports 39+ languages. Language detection happens locally using Unicode script analysis and keyword matching — no data is sent to any server for detection.

If live translation is enabled, text may be sent to your configured LLM provider for translation. This follows the same opt-in rules as Local AI Processing above.

Data Storage

  • Imported messages are stored in a local SQLite database at ~/.arcana/.
  • Media attachments are cached locally at ~/.arcana/media/.
  • You can delete all data at any time by removing the ~/.arcana/ directory or using the in-app reset function.

In-App Purchases

Emberiris offers Pro subscriptions (monthly, yearly, lifetime) via Apple's StoreKit. Payment is processed by Apple. We do not store or process any payment information.

Children's Privacy

Emberiris is not intended for use by children under 13. We do not knowingly collect any data from children.

Your Rights

  • All data is local. You have full control and can delete it at any time.
  • No data to export or request since nothing leaves your device.
  • Uninstalling Emberiris removes the app. Use in-app reset to remove user data.
